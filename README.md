# 🎌 Palmito Anime

Palmito Anime é uma plataforma web para descobrir, explorar e acompanhar alguns dos animes mais populares de todos os tempos.

## Funcionalidades

* Página inicial moderna
* Catálogo de animes
* Página de detalhes
* Página para assistir episódios
* Design responsivo
* Navegação intuitiva

## Tecnologias Utilizadas

* HTML5
* CSS3
* JavaScript

## Animes Disponíveis

* Attack on Titan
* Death Note
* Fullmetal Alchemist
* Steins;Gate
* Violet Evergarden
* Cowboy Bebop
* One Punch Man
* Yu Yu Hakusho
* Gintama
* Kuroko no Basket
* Shigatsu wa Kimi no Uso
