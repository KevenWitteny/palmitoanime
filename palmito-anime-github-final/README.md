# Palmito Anime

Catálogo de animes desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Página inicial
- Catálogo com cards
- Busca por nome, gênero ou ano
- Página de detalhes dinâmica
- Tela de player conectada
- Navegação entre animes
- Layout responsivo
- Organização em pastas

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

Abra o arquivo `index.html` no navegador.

Também é possível usar a extensão Live Server no VS Code.

## Estrutura

```text
.

├── detalhes.html
├── assistir.html

```

## Vídeos

Os arquivos `.mp4` não foram incluídos no projeto.

Para o player funcionar com vídeo real, coloque os arquivos na pasta:

```text
assets/videos/
```

com nomes como:

```text
fullmetal-alchemist-ep-1.mp4
steins-gate-ep-1.mp4
gintama-ep-1.mp4
attack-on-titan-ep-1.mp4
```
